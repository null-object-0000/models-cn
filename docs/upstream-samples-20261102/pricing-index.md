id="longcat-api-按量付费" tabindex="-1">LongCat API 按量付费 <a class="header-anchor" href="#longcat-api-按量付费" aria-label="Permalink to &quot;LongCat API 按量付费&quot;">​</a></h1><p>LongCat API 按量付费按实际 Token LongCat 平台，登录账号。</li><li>在<a href="https://longcat.chat/platform/api_keys" target="_blank" rel="noreferrer">「API Keys」</a>页面创建并获取 API Key。</li><li>中国大陆用户需要完成实名认证（详见<a id="费用如何计算" tabindex="-1">费用如何计算 <a class="header-anchor" href="#费用如何计算" aria-label="Permalink to &quot;费用如何计算&quot;">​</a></h2><p>API 请求按照输入Token（未命中缓存）、输入Token（命中缓存）、输出 Token分别计价：</p><div com"><table tabindex="0"><thead><tr><th>项目</th><th>计算方式</th><th>金额</th></tr></thead><tbody><tr><td>输入（未命中缓存）</td><td>600,000 ÷ 1,000,000 × ¥2</td><td>¥1.20</td></tr><tr><td>输入（命中缓存）</td><td>400,000 ÷ 消耗实时扣减余额。</p><p>充入余额长期有效、无过期时间，随用随扣。若账户同时存在赠送额度，赠送额度优先于充值余额扣减。</p><h3 id="如何充值" tabindex="-1">如何充值 <a class="header-anchor" href="#如何充值" aria-label="Permalink to &quot;如何充值&quot;">​</a></h3><ol><li>进入 充值订阅」</a>。</li><li>查看当前可用余额。</li><li>选择充值金额，或填写自定义金额。</li><li>点击「立即充值」，按页面提示完成支付。</li></ol><h3 id="支付方式" tabindex="-1">支付方式 <a class="header-anchor" href="#支付方式" aria-label="Permalink to tabindex="-1">退款规则 <a class="header-anchor" href="#退款规则" aria-label="Permalink to &quot;退款规则&quot;">​</a></h2><p>未消耗的充值余额，可以申请退款。</p><h3 id="退款条件" tabindex="-1">退款条件 <a class="header-anchor" 个月的订单不支持退款。</li><li>一个账户同一时间只能有一笔处理中的退款申请。</li></ul></div><div data-edition-only="ai"><ul><li>已消耗金额不支持退款。</li><li>最小退款金额为 $0.01。</li><li>微信、支付宝超过 12 个工作日到账。</p></blockquote><p>计费可能存在延迟，页面展示的可退款金额为预估金额，最终以实际到账金额为准。</p><h3 id="退款金额与路径说明" tabindex="-1">退款金额与路径说明 <a class="header-anchor" href="#退款金额与路径说明" aria-label="Permalink to aria-label="Permalink to &quot;常见问题&quot;">​</a></h2><p><strong>API 按量付费和 Token资源包有什么区别？</strong></p><p>API按量付费先充值余额再按实际 Token 消耗实时扣费，适合用量不固定、想精确控制成本的场景。</p><p>Token资源包是一次性购买固定 Token 额度，购买后 30 天内有效，与按量付费余额独立计费、互不抵扣。</p><p>同时充值API按量付费和购买Token资源包的情况，模型调用将优先消耗Token资源包中的Token，再消耗API按量付费余额。</p><p><strong>调用失败的请求会扣费吗？</strong></p><p>不会。HTTP 401 / 403 / 429 / 500 等失败响应都不会扣减余额。只有成功返回（HTTP 200）的请求才按实际 Token 用量计费。</p><p><strong>充值余额的有效期是？</strong></p><p>充入余额长期有效、不过期，会一直保留直到被消耗或退款。</p><p><strong>充值金额可以马上开票吗？</strong></p><p>不可以。预充值但未消费的金额不计入可开票金额。只有实际消费后的金额可以开票。</p><p><strong>退款期间还能继续调用 API 吗？</strong></p><p>不能。退款审核期间，账户 API 调用会暂停，也无法继续充值。</p><p><strong>余额不足时会怎样？</strong></p><div data-edition-only="chat com"><p>余额不足或余额小于等于 ¥0 时，新的 API 请求会被拒绝。充值后余额大于 ¥0 即可恢复。</p></div><div data-edition-only="ai"><p>余额不足或余额小于等于 $0 时，新的 API 请求会被拒绝。充值后余额大于 $0 即可恢复。</p></div><div data-edition-only="chat com"><p><strong>发票多久能开好？</strong></p><p>通常 1–3 个工作日内开具。开具完成后会发送至你填写的邮箱，也可以在开票记录中下载。详见<a
